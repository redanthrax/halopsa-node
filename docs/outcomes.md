# Outcome Operations

Ticket/action outcomes (`/api/Outcome`, `TOutcome` schema). Also used by the Action resource outcome dropdown.

## Get Many

**Return All**, **Limit**, and filters: **Ticket Type ID**, **Workflow ID**, **Quick Only**, **Show Hidden**, **Exclude System Actions**.

## Get by ID

**Outcome ID** with optional **Include Details**.

## Create

`POST /Outcome` with **Additional Fields** (single object or array).

## Delete

Delete by **Outcome ID**.
