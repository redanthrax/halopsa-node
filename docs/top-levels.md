# Top Level Operations

Organisation tree / top-level nodes (`/api/TopLevel`, `Tree` schema).

## Get Many

**Return All**, **Limit**, **Search**, **Organisation ID**, **Show All**, **Include Agents**, **Include Teams**.

## Get by ID / Create / Delete

**Top Level ID** for get and delete. Get supports **Include Details**, **Include Agents**, **Include Teams**. **Create** uses **Additional Fields** (object or array).
