# Canned Text

Predefined response snippets (`/api/CannedText`). Supports list, get by ID, create, and delete per OpenAPI.

## Operations

- **Get Many** — `GET /CannedText` with optional agent, team, department, group, `showall`, and `ticketonly` filters
- **Get by ID** — `GET /CannedText/{id}`
- **Create** — `POST /CannedText` with JSON body fields
- **Delete** — `DELETE /CannedText/{id}`
